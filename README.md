Steps to run the project efficiently:
1) Please open the Educare_Final(1).ipynb and run it on Google Colab, and run the backend logic.
2) Connect to your Google Drive and create a folder called (educareai).
3) Then download the final_revised_educare_frontend.zip and extract its contents
4) Then open StackBlitz and drag the folder content into the project tree.
5) Update the Public URL in the .env file to suit the ngrok Public URL in the backend notebook run in Google Colab.
