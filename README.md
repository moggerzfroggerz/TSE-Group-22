Steps to run the project efficiently:
1) Please open the Educare_Final.ipynb and run it on Google Colab, and run the backend logic.
2) Then download the educare_front_complete.zip and extract its contents
3) Then open StackBlitz and drag the folder content into the project tree.
4) Update the Public URL in the .env file to suit the ngrok Public URL in the backend notebook run in Google Colab.
