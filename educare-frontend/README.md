## How to Run locally

This project is built using **Vite + React**. Follow these steps to run the skeleton UI on your local machine:

**Prerequisites:** You must have **Node.js** installed.

```bash
# 1. Clone this repository
git clone [https://github.com/yourusername/educare-frontend.git](https://github.com/yourusername/educare-frontend.git)

# 2. Navigate to the project folder
cd educare-frontend

# 3. Install the dependencies
npm install

# 4. Start the development server
npm run dev
